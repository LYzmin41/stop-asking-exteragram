# No Call Confirmation

## Goal

Make audio and video call buttons start the call immediately by removing only the confirmation dialog. The plugin has no settings.

## Scope

- Add one ExteraGram Python plugin module.
- Hook `VoIPHelper.startCall` overloads and mutate only the seven-argument user-call boolean flag.
- Preserve ExteraGram's permission, account, network, and call setup logic.

## Confirmed context

- The requested workspace was empty and had no Git repository or project-specific instructions.
- Local APK evidence is ExteraGram `12.9.0` with Plugin SDK `1.4.5.1`.
- `ChatActivity` routes both audio and video header actions to the six-argument `VoIPHelper.startCall` overload.
- That overload delegates to the seven-argument overload with a final `false` value.
- The seven-argument overload calls `AlertsCreator.createCallDialogAlert(...)` when that final value is false; `true` continues through the existing call/permission flow.

## Decision

Use the SDK's `hook_all_methods` for `VoIPHelper.startCall`, then mutate `param.args[6]` only for seven-argument calls whose final value is a Python boolean. This avoids the separate seven-argument group-call overload, whose last argument is an `AccountInstance` rather than a confirmation flag.
